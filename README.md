# Documentum - Documentation as Code

A python based project of command utilities to publish documentation as code

## Installation

```
cd documentum
./install.sh

# ./install.sh merchromio
# ./install.sh scribiosa
```

## merchromio

Podman utility image for rendering Mermaid `.mmd` files to image files for Pandoc input.

Pandoc must be available on host machine

the image uses:
- mermaid-js/mermaid-cli
- puppeteer
- chromium

### Usage

```bash
merchromio \
    -i diagram.mmd \
    -o diagram.png
```

The command mounts the current directory at `/work` and uses a container-local writeable `/tmp` for Chromium.
Rendered files retain the UID and GID of the user who runs `merchromio`.

Paths are relative to the current directory.

Run `merchromio` without arguments, or pass `--help`, to see the ommonly used renderer options and examples.  The wrapper passes other supported Mermaid CLI (`mmdc`) options to the container.

### Multi-stage Dockerfile

**Build**

- `root` required to install system packages and npm dependencies

**Run**

UID
: merchromio `2001`

Working Directory 
: /tmp

## scribiosa

A standalone documentation-as-code command that builds linked Markdown documents ito HTML, DOCS or PDF.

### Usage

```bash
# starting at root document, generate all documents
scribiosa conjure docs/root.md

# generate all documents in all supported formats
scribiosa conjure docs/root.md --format all

# output directory of generated documents default to `mktemp -d`
scribiosa conjure docs/root.md --output-dir DIRECTORY

# no build report
scribiosa conjure docs/root.md --no-build-report
```

A build report is generated by default alongside the the other files, rendered in the same `--format` as the build (or in every format when `format-all` is used).  The report is named `build-report` with the matching extension including the following information:

- Build Information
- Settings
- Build Log
- Root Document, linked to generated files
- Generated Files
